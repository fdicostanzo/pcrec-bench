# bench/unusual/inline/ -- the INLINE pcrec callout arm's ENTRY files ([B148], lane b148inline)

GENERATED by `bench/unusual/gen_inline.py` (`--check` re-derives; `tools/check_inline.py` checks).
Nothing here is timed or compiled yet: part 2 of the lane wires `testees/pcrec/adapter.py`.

- `<arm>.rxt` -- one ENTRY file per pcrec-spelled callout arm (`co-luhn`, `co-isbn`, `co-member`,
  `co-netstr` real; `co-luhn-pass`, `co-isbn-pass`, `co-member-pass` stub). It holds ONE line:
  `include "../callees/ub_<callee>.rxt" sha256 <hex64>` (pcrec [INLINE-C] stage 3's pin). The
  harness-style compile is `pcrec --allow-code=c --include-block <fragment>:<line> <entry> ...`.
- `blocks.tsv` -- arm, kind, form (plain / whole-subject), callee, member_arg, fragment, line,
  entry, fragment_sha256: which `pattern-esc` line of which fragment is which arm's pattern.

The FRAGMENTS (`../callees/ub_<callee>.rxt`) carry the patterns with the callee body inline as
``(?C`c[,consume]: ... `)``. Only the pcrec arm is spelled inline: `patterns/*.rx` are untouched.

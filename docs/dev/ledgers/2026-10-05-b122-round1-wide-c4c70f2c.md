## 7. THE WIDE SWEEP (lane b122sweep): the complete mover list + the null

Script `docs/dev/measurements/probe_b122_sweep.py`, archive
`docs/dev/measurements/2026-10-05-b122-sweep.txt` (re-runnable,
deterministic — two runs diff byte-identical). Read-only over the same
eight TSVs as §1-§6 plus the §2 census; no compile, no run, no timing,
no store load.

**Section is `d119`/`null_band`, not `rank` — stated once.** The
reporter's R8 column (`delta_verdict`, the brief's own column 18) lives
on `rank` rows too, but `rank` carries no identity and no noise
threshold. The `d119` section ([B79], `docs/design/null_band_v1.md`) is
the reporter's OWN per-cell cross-pin machinery: it already carries, per
set-grain cell, (a) IDENTITY from the record's `program_sha256` FIELD
(schema v1.7, field-first — not re-derived here, not the census's own
verdict, though the two never disagree on any of the 1,255 identical +
702 changed rows this sweep read) and (b) a bar = max(within-window
IQR%, the null band's own half-width for that cell's (regime,
baseline-scale) stratum) — where the null band's half-width over a
stratum IS, by construction, that stratum's identical-population's own
observed |Δ%| range (§null_band_v1.md §3-4). That is exactly the rule
this task's brief proposes ("a changed-program mover is real only if it
lies outside the identical-program population's ratio range"), already
measured by the reporter, PLUS the within-window IQR the brief did not
ask for.

**THE RULE** (stated before being applied, per the script's own
docstring): THE NULL population per report = every `d119` cell whose
`program_sha256`-FIELD identity reads `identical`. A changed-program
cell is a REAL mover iff the reporter's own D119 bar fires
(`value` in {regress, improve}); a changed cell whose bar reads `within`
is NOT a real mover even if R8's own 2×stddev criterion (column 18)
says faster/slower. As a cross-check against the brief's own literal,
cruder wording (pooled across regimes/strata rather than per-stratum),
the sweep also computes, per (set, route), the identical population's
own pooled max|Δ%| and asks whether a changed+bar-fired cell's |Δ%|
exceeds IT — **agreement on 548 of 702 changed rows (78.1%)**; 141 rows
read real by the bar alone (the pooled rule is cruder, not wrong — a
stratum's own band can be narrower than the set/route's pooled max); 13
read real by the pooled rule alone (that cell's own stratum happens to
have a WIDER band than the pooled reading, so the per-stratum bar is the
more conservative one there). Full 1,255-row identity sanity check: 1,255
of 1,255 `identical` rows read the reporter's own `null-control` bar
token (never scored against a band) — confirms the two paths cannot
drift apart within one run.
